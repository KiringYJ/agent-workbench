# Gemini Notes

Gemini can use `GEMINI.md` as a thin entrypoint that references `AI_AGENT_GUIDE.md` and `AI_AGENT_PROJECT.md`.

Gemini CLI discovers project Agent Skills under `.agents/skills/`. Do not create a `.gemini/skills/` mirror solely for discovery. Keep `GEMINI.md` limited to imports or genuinely Gemini-specific loader behavior.
